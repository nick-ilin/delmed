# MedD — Онлайн-маркетплейс для аптеки

**MedD** — это демонстрационный проект, разработанный для портфолио. Он симулирует работу интернет-аптеки, разделенную на две независимые части: админку для управления ассортиментом и публичный магазин для заказа лекарств.

Цель проекта — показать на практике современные подходы к разработке и основные технологии, используемые в коммерческой разработке.

## 🚀 Быстрый старт

### Требования
- Установленные **Docker** и **Docker Compose**

### Запуск
1.  **Склонируйте репозиторий:**
        bash
    git clone https://github.com/nick-ilin/delmed.git
    cd medd
    
2.  **Запустите все сервисы из корневой директории:**
        bash
    docker-compose up -d
    
3.  **Дождитесь полной загрузки всех сервисов** (первые запуски могут занять несколько минут).

### 🌐 Доступ к сервисам после запуска

| Сервис | URL | Логин / Пароль |
| :--- | :--- | :--- |
| **Админ-панель (Angular)** | [http://localhost:4200/admin](http://localhost:4200/admin) | - |

## 🧱 Архитектура и технологии

Проект состоит из следующих ключевых компонентов:

| Компонент | Назначение |
| :--- | :--- |
| **Catalog API** | Сервис-админка для управления лекарствами (CRUD). |
| **Order API** | Пользовательский сервис для отображения товаров и оформления заказов. |
| **Shared.Contracts** | Библиотека с общими контрактами для обмена данными между сервисами. |
| **Catalog Frontend** | Интерфейс администратора на Angular. |
| **PostgreSQL** | Реляционные базы данных для каждого сервиса. |
| **RabbitMQ** | Брокер сообщений для асинхронной связи. |

### 🔄 Поток данных
1.  Администратор добавляет лекарство через админ-панель (Angular).
2.  **Catalog API** принимает запрос, сохраняет лекарство в свою БД и отправляет событие MedicineAddedEvent в RabbitMQ.
3.  **Order API** получает это событие и сохраняет копию лекарства в свою БД.
4.  Пользователь в магазине видит актуальный список лекарств и может оформить заказ через **Order API**.

### 🛠️ Стек технологий
*   **Backend API:** .NET 8, C#, ASP.NET Core
*   **Архитектура:** Микросервисы, CQRS, MediatR
*   **Базы данных:** PostgreSQL 16, Entity Framework Core
*   **Асинхронное взаимодействие:** RabbitMQ, MassTransit
*   **Фронтенд:** Angular 21, TypeScript, SCSS
*   **Инфраструктура:** Docker, Docker Compose, Nginx
